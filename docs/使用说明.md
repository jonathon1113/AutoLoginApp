# 使用说明

本文档面向**使用者**：从零开始，把一张 Excel 设备表变成「双击分组卡片即可批量登录」。

- 只想快速上手 → 看完 [1. 三分钟上手](#1-三分钟上手) 就够了；
- 想了解每个菜单 → [4. 菜单一览](#4-菜单一览)；
- 登录失败、界面报错 → [7. 常见问题](#7-常见问题)。

---

## 1. 三分钟上手

### 1.1 安装依赖

```bat
pip install -r requirements.txt
```

首次使用需要把 Chromium 装到 Playwright 期望的位置（与打包流程使用同一套路径解析逻辑）：

```bat
set PLAYWRIGHT_BROWSERS_PATH=0
playwright install chromium
```

> PowerShell 请写成 `$env:PLAYWRIGHT_BROWSERS_PATH=0`。

### 1.2 运行

```bat
python main.py
```

### 1.3 第一次使用

1. 菜单 **文件 → 创建Excel模板**，生成 `devices_template.xlsx`（含 5 行虚构示例，直接覆盖即可）；
2. 在 Excel 里填好设备信息；
3. 菜单 **文件 → 从Excel导入**，选择刚填好的表；
4. 左侧出现分组卡片，**双击分组卡片**即可批量登录该组设备。

## 2. Excel 模板格式（6 列）

| 设备名称 | 登录地址(URL) | 用户名 | 密码 | 分组 | 模板 |
|---------|-------------|-------|-----|-----|------|
| 示例设备A | http://192.0.2.10:8080/login | demo_user | demo_password | A组-虚拟化 | default |
| 示例设备B | https://example.com/login | demo_admin | demo_password | A组-虚拟化 | proxmox |

规则：

- **登录地址**是唯一必需列；表头支持中文别名（「登录地址」「URL」「地址」等），
  缺列会**明确报错**而不是静默产出错误数据；
- 「模板」列可留空，留空表示使用通用智能识别；
- 支持多工作表、重复设备检查、逐行错误汇总；
- 导入完成后密码以密文写入 `devices.json`，**不会**留在 Excel 以外的明文文件里；
- 导入是**后台线程**执行的，界面全程可点，导入大表也不会「未响应」。

## 6. 登录相关

### 6.1 表单识别

程序把页面输入框按 **用户名 / 密码 / 验证码 / 登录按钮** 四类角色分类，
依据 `type` / `name` / `id` / `placeholder` / `autocomplete` / `aria-label` / 样式 /
可见性 / 可编辑性等证据分级加权判定。

设备配置了模板名时 → **先用模板定位**，模板失效才**回退到通用智能识别**。

### 6.2 登录模板

模板是 `templates/*.json` 纯文本文件，**程序不会覆盖用户手工维护的内容**。

| 操作 | 语义 |
|------|------|
| 追加当前选择器到默认模板 | 只增加新选择器，默认模板原有内容一个不动 |
| 合并指定模板到默认模板 | 与指定模板取并集（去重），默认模板原有内容一个不动 |
| 用内置版本替换默认模板 | 整体覆盖，**必须由用户明确确认** |

格式与维护细节见 [`模板维护说明.md`](模板维护说明.md)。

### 6.3 验证码

- **自动识别（默认开启）**：4 位「数字 + 大小写字母」图片验证码，自动识别 → 填写 → 提交，
  失败自动刷新重试；**区分大小写**；
- 识别不出、或站点不是图片验证码时，会**定位并高亮**验证码输入框，等待人工输入后自动提交；
- 可以一键关闭自动识别，退回人工处理；
- 参数含义与调参建议见 [`验证码自动识别说明.md`](验证码自动识别说明.md)。

### 6.4 结果判定

登录成功与否由**页面真实状态**判定（登录后跳转、出现用户信息、错误提示消失等），
不是「点了提交就算成功」。失败时日志会给出**逐候选诊断**（候选序号、选择器、
是否命中、耗时、剩余预算、角色判定与拒绝原因）。

## 7. 常见问题

| 现象 | 原因 | 处理 |
|-----|------|------|
| 启动报 `Executable doesn't exist ... chromium` | 浏览器未安装到期望路径 | `set PLAYWRIGHT_BROWSERS_PATH=0` + `playwright install chromium` |
| 提示找不到浏览器（EXE） | 打包时未加 `--collect-all playwright` | 用 `build.bat` 重新打包 |
| EXE 首次启动很慢 | 需要解压内置 Chromium | 属正常现象，等待即可 |
| 登录提示「Form not found」 | 页面结构与模板不匹配 | 用「工具 → 保存登录模板」重新录制选择器 |
| 登录提示「密码错误」 | 凭据错误或页面真实报错 | 检查 `devices.json` 中的账号密码；诊断日志会给出具体拒绝原因 |
| 找不到验证码 | 页面验证码图片结构特殊 | 见 [`验证码自动识别说明.md`](验证码自动识别说明.md) 的「定位策略」 |
| HTTPS 证书告警 | 站点证书不受信 | 已内置忽略证书策略；若仍出现，程序会尝试点击「高级 → 继续」 |
| 切换电脑后无法解密 | 加密密钥与机器相关 | 重新用 Excel 导入设备数据 |
| 界面显示「未响应」 | — | 导入已完全后台化；若仍复现请附 `app.log` 反馈 |

---

## 8. 注意事项

1. 程序会在**当前目录**生成 / 读取 `devices.json`、`devices_template.xlsx`、
   `login_logs.db`、`app.log`；
2. 首次启动需解压内置浏览器与运行时（约 600MB），耗时较长属正常现象；
3. **切换电脑后需要重新导入 Excel**（加密密钥与机器相关）；
4. 浏览器为**有头模式**，可人工接管；退出程序自动回收全部浏览器进程；
5. 本仓库不包含任何真实凭据、真实内网地址或真实设备配置；
   诊断日志只输出**非敏感属性**，不输出任何账号、密码或验证码内容。
